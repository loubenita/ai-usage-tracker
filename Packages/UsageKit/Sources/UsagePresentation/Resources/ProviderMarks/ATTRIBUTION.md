# Provider mark attribution

The app bundles these marks so it can show the provider while offline. They identify the
provider whose usage is being shown. Brand names and marks remain the property of their
respective owners. Their inclusion does not imply endorsement.

Retrieved 2026-09-27:

| Mark | Bundled file(s) | Source |
| --- | --- | --- |
| Claude Code | `claude.svg` | [Simple Icons' Claude SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/claude.svg). Simple Icons publishes its files under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). |
| Codex | `codex.png` | A byte-for-byte icon from the signed Codex desktop app, bundle identifier `com.openai.codex`, version 26.915.31945. [OpenAI's brand guidance](https://openai.com/brand/) says marks may be used only for work directly related to OpenAI services. The current public brand kit has no separate downloadable Codex mark. |
| Cursor | `cursor-light.svg`, `cursor-dark.svg` | [Cursor's brand-assets download](https://ptht05hbb1ssoooe.public.blob.vercel-storage.com/assets/brand/cursor-brand-assets.zip). These are its `CUBE_2D_LIGHT.svg` and `CUBE_2D_DARK.svg` files. |
| Kiro | `kiro.png` | [Kiro's official favicon](https://kiro.dev/favicon.ico). It was converted to PNG without visual changes because AppKit loads that format directly. |
| Antigravity | `antigravity.png` | [Google Antigravity Press Assets](https://www.antigravity.google/press), using the supplied [full-color icon](https://www.antigravity.google/assets/image/brand/antigravity-icon__full-color.png). |
| OpenCode | `opencode.svg` | [OpenCode's official favicon](https://opencode.ai/favicon.svg). Its [brand page](https://opencode.ai/brand) also makes brand assets available. |

Each mark keeps its original shape. Cursor uses the provider-supplied light or dark
version to match macOS appearance. The other provider-supplied marks retain sufficient
contrast in both appearances.
